# Markosh Karki Portfolio

A modern minimal portfolio for Markosh Karki, an aspiring AI Engineer and Data Scientist.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Content

- Projects: `content/projects`
- Blog posts: `content/blog`
- Site settings: `content/site`
- Admin panel: `public/admin`

## Deploy

Import the repository into Vercel, keep the default Next.js settings, and set the custom domain to `markoshkarki.com.np`.
