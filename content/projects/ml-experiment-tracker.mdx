## Overview

This project keeps machine learning experiments organized without requiring a complex MLOps platform. It is designed for student projects, prototypes, and early portfolio work.

## Features

- Run metadata and metric comparison
- Dataset and parameter notes
- Simple charts for accuracy, loss, and latency

## Next steps

The next iteration will support CSV imports and a cleaner export flow for project reports.
